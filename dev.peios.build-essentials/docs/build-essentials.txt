dev.peios.build-essentials — the ambient Peios userland build floor.

It provides the legacy build-essentials role and pulls in the shell and tools
that every Pekit build may assume without declaring them individually: dash
(including the sh role), Peiosutils, Diffutils, Findutils, Gawk, Grep, Make,
and Sed.

Peiosutils is Peios's Coreutils implementation. Keeping it in the baseline
ensures build roots exercise the same fundamental userland that ships on the
installed system and prevents conflicting ownership of standard utility paths.
The non-overlapping GNU build-compatibility supplement provides chgrp, chmod,
and chown for conventional upstream build systems; it contains no command path
owned by Peiosutils.

This package contains no compiler. Select dev.peios.build-essentials-c,
dev.peios.build-essentials-c++, or dev.peios.build-essentials-rust for a
language toolchain.
