build-essentials — the ambient userland floor for building packages.

Pulls the shell and tools every build may assume without declaring them:
dash (sh), bootstrap coreutils, sed, grep, gawk, findutils, diffutils, make.

The bootstrap coreutils supplies POSIX build operations such as `chmod` which
Peios's installed-system peiosutils intentionally does not implement.

Deliberately contains no compiler: toolchains live in the per-language
stacks (build-essentials-c, build-essentials-c++, ...).
